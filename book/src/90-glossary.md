# Glossary of mechanics

Every mechanic in the taxonomy, grouped by family. Each row gives the mechanic's one-line summary, the number of catalog games that use it, and the release year of the first catalog game that does. The name links to the full record, with the definition, the levers a designer can turn, the failure modes, and the sources.
